# DNEM v7.7 Research Runtime v1.0

The DNEM v7.7 Research Runtime connects the operational measurement specifications to executable testing pipelines through two operational pathways:

---

## 1. Interactive Participant Test Chamber (Empirical Human Testing)

Allows researchers and participants to take laboratory-grade cognitive tests in real-time in the browser.

### Key Features:
1. **Live Paradigms**:
   - **Stroop Color-Word Interference (`C05-01`)**: Measures semantic interference and inhibitory control with congruent/incongruent color words.
   - **2-Back Working Memory (`C02-01`)**: Rapid sequential letter stream evaluating memory buffer updating, hit rate, and false alarms.
   - **Choice Reaction Time (`C03-01`)**: Lateralized stimulus response latency (`[←]` vs. `[→]`) with randomized foreperiod fixation crosshair.
   - **Eriksen Flanker Task (`C04-01`)**: Evaluates selective attention and distractor suppression with arrow arrays (`<<<<<`, `<<><<`).
   - **Matrix Reasoning (`C01-01`)**: Fluid non-verbal inductive reasoning evaluating geometric pattern completion.
2. **Sub-millisecond Timing Precision**: Stimulus onset, keyboard dispatch, and button inputs are recorded using browser `performance.now()`.
3. **Foreperiod Jitter & Inter-Trial Intervals (ITI)**: Prevents motor rhythm anticipation.
4. **Data Locking & Provenance**: Human trials are submitted via `POST /api/v1/sessions/:id/submit-human-trials`, generating a canonical SHA-256 dataset checksum and transitioning the session state machine to `LOCK`.

---

## 2. Automated Synthetic Batch Engine (Multi-Measurement Simulation)

Provides deterministic simulation of measurement batteries across all 170 operational specifications:

1. Measurement IDs are selected from the 170-item registry.
2. A protocol is compiled.
3. Synthetic trials are generated under a deterministic PRNG seed.
4. Trial records follow the Universal Trial Contract fields.
5. Results are aggregated into raw, derived, and task-score layers.
6. Persistence is available through SQLite.
7. Backend exposes `/api/v1/research/compile-run`.

---

## Scientific Boundaries & Epistemic Separation

- **Synthetic Trials vs. Empirical Observations**: Synthetic trials generated by the batch engine are computational scaffolds for statistical pipeline verification; they are strictly partitioned from empirical human observations.
- **Task Scores vs. Construct Validation**: Task-level scores (accuracy, mean RT, interference costs) do not constitute construct validation without confirmatory psychometric modeling (CFA/SEM).
- **Epistemic Disclaimers**: No clinical, diagnostic, or universal intelligence inference is asserted. Real stimulus adapters, participant privacy controls, psychometrics, multimodal acquisition, and cross-site replication remain separate validation stages.
