# DNEM v7.7 Sensitivity & Robustness Analysis Engine v1.0

The engine compares a primary analysis with explicitly registered sensitivity
runs.

Sensitivity runs can represent alternative:
- exclusion rules
- missing-data handling
- model specifications
- other declared analytical choices

Outputs include:
- absolute estimate change
- relative estimate change
- direction consistency
- number of sensitivity runs

The engine intentionally reports descriptive robustness evidence. It does not
define a universal robustness threshold and does not automatically upgrade a
claim to validated status.
