# DNEM v7.7 — Operational Measurement Specifications 170

The executable registry now resolves all 170 measurement families to an operational
specification containing task metadata, stimulus/response contract, trial structure,
raw and derived measures, scoring, QC, difficulty configuration, study-builder
configuration, trial schema, result schema, evidence-graph metadata and replication
requirements.

Important scientific boundary:

These are **operational specifications**, not empirical validation results.
Generic task templates are implementation contracts. Domain-specific stimulus
content, normative parameters, psychometric estimates and construct validity must be
established by research and validation.
