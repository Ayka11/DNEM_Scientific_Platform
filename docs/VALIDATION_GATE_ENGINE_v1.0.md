# DNEM v7.7 Validation Gate Engine v1.0

Mandatory promotion gates:
1. Reliability
2. Construct validity
3. Stability
4. Invariance
5. Replication
6. Generalization

Default policy: BLOCK.

Task scores may exist without a construct estimate. A construct estimate is released
only when machine-readable evidence explicitly satisfies all mandatory gates.

The engine does not manufacture evidence and does not itself establish scientific
validity; it enforces the boundary between implementation and empirical evidence.
