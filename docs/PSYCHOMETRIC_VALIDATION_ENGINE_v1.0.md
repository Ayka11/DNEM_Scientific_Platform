# DNEM v7.7 Psychometric Validation Engine v1.0

Implemented computational procedures:

- descriptive statistics
- Pearson correlation
- Cronbach alpha
- split-half correlation
- test-retest correlation
- paired mean change
- group difference
- invariance screening
- criterion correlation

The engine separates **statistic calculation** from **scientific gate decisions**.

A computed alpha, correlation, group difference, or screening statistic does not
automatically pass reliability, validity, stability, or invariance.

Thresholds, study design, sample adequacy, measurement model, preregistration,
missing-data treatment, multiplicity, and domain-specific scientific justification
must be specified before a result can be treated as validation evidence.

This is an implementation component, not a claim that DNEM constructs have been
scientifically validated.
